# Bundled school marks

These twelve PNG files are local copies of the existing application's identification assets.
`sources.json` retains their original source page and image URL. No runtime access to the old
application or remote image service is required.

University names and marks belong to their respective owners and are not covered by this
project's source-code license. Their display identifies a user's target school and does not
imply endorsement. Fictional or unrecognized institutions use generated letter initials.
