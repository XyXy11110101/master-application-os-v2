## 2. 离线研究与材料检查

Stanford、Harvard、UCL 相关用例为 **synthetic（合成）回归样例**，用于重现旧版暴露过的错误形态。它们不是当前官方要求全文，不是人工复核金标准，也不能用于报告这三所学校的研究准确率。

- Stanford 形态样例覆盖短答的字符单位、选交陈述、明确不要求、独立语言分数，以及目的陈述的词数和页数建议共存。
- Harvard 形态样例覆盖同页不同学位范围，避免把明确属于 PhD 的规则用于硕士项目。
- UCL 形态样例覆盖从项目导航发现中央政策，以及拒绝将另一所大学当作同校官方来源。
- 复核否定某个限制时，只移除或标记对应字段，不因该字段问题隐藏已有依据的材料核心；尚未确认的范围、申请季或冲突字段继续保留。
- 缓存与调用测试使用可记录请求的模拟传输。重复请求命中缓存、取消不继续请求、错误响应可本地重解析的结果，均属于离线软件行为验证。
- TXT、Markdown、DOCX 和本地生成的有效文本 PDF 已完成解析测试；PDF 用例实际调用 PDF.js 读取文件结构。该用例不是官方 PDF 全面兼容性验证，也不代表扫描 PDF 可以被识别。
- 文件检查与文件版本、要求修订绑定。未知页数、不可读文本和未解决要求不会被当作可靠通过；DOCX 不凭缓存或估计页数判定合规。
