## 本次实现

- 目标入学年份、可选月份、学位层次与具体学位名称分别保存；支持自定义年份、学校别名复用、城市时区搜索。
- 会话草稿按工作区实际路径和记录隔离，跨导航保留，正常关闭提示未保存；恢复备份不继承原工作区的未保存草稿。
- 新限制数值留空；个人日期快捷选择；首页准确定位推荐人、研究、项目信息及提交记录；材料按名称与版本两步选择。
- 本科、硕士、博士使用明确研究上下文。入学年份与截止年份、具体批次分别核对；缓存、继续和采用不能跨范围串用。
- SQLite schema 1 在完整备份后升级到 schema 2，旧申请季原文保留；补充范围使相关要求检查过期，个人进度和文件保留。不同已确认入学批次通过复制项目信息分别管理。
