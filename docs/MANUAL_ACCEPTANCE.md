# V2 实际体验验收

本轮交付为 0.2.0 候选版。以下项目需要人在实际 Windows 窗口中完成；代码测试和截图不替代这些结果。

## 先看新版是否符合预期

1. 打开 `out/Application Desk V2-win32-x64/ApplicationDesk.exe`。
2. 点击“体验虚构演示”。演示与个人工作区隔离。
3. 先停留在“现在”页面五秒，记下你认为应该做的第一件事；再点击进入准备清单。
4. 查看“我的学校”和项目里的材料详情，试着保存备注、改为等待并填写回访日期，再撤销这次进度。
5. 将窗口缩窄，用 `Ctrl` + `+` 放大。检查主行动、文字、导航、材料列表和返回按钮是否容易找到。
6. 记录不自然或看不明白的地方，以及你是否认可视觉、信息密度和操作感。

记录：测试者、日期、五秒内找到的行动、是否需要解释、操作卡点、视觉认可（是／否／需调整）。

## 本机完整流程

1. 在设置切换个人工作区。选择目标入学年份、可选月份和个人时区。
2. 预览旧名单，检查来源、缺失官网和已移出项目，只勾选要导入的项目。重复导入同一项目不应新增副本。
3. 给一个测试项目建立手动事项，导入一份测试文件并保存关联，运行本地检查。
4. 修改原文件后导入新版本，确认旧版本仍在，其他项目原有选择不变化。
5. 关联推荐人，记录邀请、等待及回访；分别记录准备完成、实际提交、正式确认、学校收齐。
6. 在设置导出备份，关闭再启动程序确认记录。恢复备份后应进入独立工作区，原工作区保留，密钥需要重新配置。

官网研究需自行配置服务。先从一个项目开始，检查渐进结果的原文、网址、时间与范围，采用部分结果后再核对后续差异。不要把网页成功获取当成结论已经核实。

## 安装与独立系统

在干净 Windows 环境安装 `ApplicationDeskV2-Setup.exe`，验证首次启动、文件导入、备份恢复、后续版本升级及卸载。

- 安装目录：`%LOCALAPPDATA%\ApplicationDeskV2`
- 资料目录：`%LOCALAPPDATA%\ApplicationDeskV2Data`
- 卸载后应保留资料目录；重新安装应能打开原工作区。
- 当前没有经过两个实际发行版本的升级验收，模拟版本标记测试不替代它。

请按实际操作记录通过或失败，并保留错误提示。未操作的项目填写“待验收”。


## 0.2 本轮需要你的实际操作

当前状态：待验收。自动化使用独立临时工作区和隐藏 Electron 测试窗口；原生对话框使用测试替身，不替代你的操作。

1. 新增测试项目：选择本科／硕士／博士，分别填写具体学位名称；试一次自定义入学年份、城市时区和学校别名。确认能理解“入学年份”。
2. 填写一半事项后点“稍后继续”，切换到材料，再回到项目继续填写。试一次“放弃修改”和关闭应用时“返回继续填写”。
3. 从首页点击推荐人行动，确认直接进入对应联系人。等待日期试“明天”和“一周后”。
4. 用系统文件选择器导入两个版本，在项目中搜索材料、选择旧版本，再确认其他项目未跟随改变。
5. 缩窄窗口，并在 Windows 实际 200% 缩放下使用键盘操作所有选择器，检查可读性、焦点和按钮位置。
6. 用旧工作区升级，检查原申请季原文、待确认年月、迁移备份和重启记录；确认目标后，旧要求应提示核对且个人进度仍在。
7. 在自行配置的服务上分别研究本科、硕士、博士官方项目，人工对照证据和适用批次。此项尚未用真实模型服务验收。

安装、实际升级、卸载数据保留及视觉认可仍需按前文分别记录，未执行不可标通过。
