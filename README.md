# 申请工作台

在自己的电脑上，把学校要求、申请材料、推荐信和提交进度放在一起。

**添加项目 → 查阅官方要求 → 准备材料 → 记录提交与收件。**

适用于 Windows x64。当前版本 **0.2.1** 为预发布版。

[下载安装包与完整 ZIP](https://github.com/XyXy11110101/master-application-os-v2/releases/tag/v0.2.1) · [开发指南](docs/DEVELOPMENT.md)

## 开始使用

1. 运行安装包，或完整解压 ZIP，打开 `Application Desk V2-win32-x64` 文件夹中的 `ApplicationDesk.exe`。
2. 建立个人工作区，选择目标入学年份和时区；也可以先体验隔离的虚构演示。
3. 添加学校和项目，从“现在”查看下一步行动。没有 API 也能管理清单、文件、推荐信和提交记录。

安装包目前未签名。已知限制及实际完成的检查见对应版本的发行说明。

## 四个入口

| 入口 | 可以做什么 |
| --- | --- |
| 现在 | 找到当前行动，安排等待和回访 |
| 我的学校 | 按学校管理项目，查看要求、准备清单和提交收件 |
| 我的材料 | 导入文件副本、保留版本，为每个项目独立选择版本 |
| 设置 | 管理入学时间、时区、模型服务，导入旧项目名单和备份恢复 |

年份表示目标入学年份；本科、硕士、博士表示目标项目层次。月份可以暂不确定。准备完成、实际提交、正式确认和学校收齐分别记录。

## 数据保存在本机

工作区和材料位于 `%LOCALAPPDATA%\ApplicationDeskV2Data`，与安装目录分开。导入文件时保存副本，原件不变。设置中可以导出备份，恢复时建立独立工作区。

API 密钥由 Windows 加密保存，不进入备份；换电脑后需重新配置。旧版仅导入项目名单，既有要求和个人进度不会自动迁入。

## 有依据的官网研究

可以配置兼容 Chat Completions 的服务，为本科、硕士和博士项目查阅官方资料。仅发送研究所需的公开文本，不自动上传个人文件或背景。

结果带来源和适用范围，由你选择采用；未知与冲突会保留。研究结果不等于资格确认，也不代表材料已经完成。每轮最多 30 页、12 次模型调用、15 分钟；继续研究需要主动操作，重启不会自动续查。调用费用由所选服务计收。

本地文件检查支持 TXT、Markdown、DOCX 和文本 PDF 的可靠提取内容；它检查已知长度限制，不判断录取质量或推断未知页数。

## 开发与许可

使用 Electron、React、TypeScript 和 SQLite 构建。运行、测试和发布步骤见 [开发指南](docs/DEVELOPMENT.md)，设计说明见 [架构](docs/ARCHITECTURE.md)。

当前不提供文书生成、邮箱抓取、自动网申、跨设备同步或多人账户。
