# 申请工作台 V2

一个在 Windows 本机运行的申请工作台：添加项目、查阅有来源的要求、准备和复用材料、记录推荐信与提交收件。

V2 是独立代码库。旧版 Python/NiceGUI 的程序、工作区和历史不参与新版运行。

当前版本为 **0.2.0 待验收版**。Windows x64 安装包与完整 ZIP 在 [GitHub Releases](https://github.com/XyXy11110101/master-application-os-v2/releases/tag/v0.2.0) 下载。供 Grok 或其他独立验证者使用的入口是 [独立验证指南](docs/EXTERNAL_VALIDATION.md)，包含运行命令、验证重点与报告格式。

## 使用

从发行目录运行 `ApplicationDeskV2-Setup.exe`，或打开解压包中的 `ApplicationDesk.exe`。不需要安装 Python、Node.js 或数据库。

第一次打开可以建立个人工作区，也可以体验隔离的虚构演示。演示里的学校、政策与材料均为虚构，不能用于真实申请。

四个入口：

- **现在**：当前可以做的一个重点，其他可并行事项与等待回访。
- **我的学校**：同校项目、准备清单、要求与证据、研究结果、提交和收件。
- **我的材料**：导入副本、保留版本；每个项目独立选择文件版本。
- **设置**：目标入学年份、可选月份、城市时区、可选 API、旧名单导入、工作区备份和恢复。

材料导入后需在项目中保存关联；文件导入、准备完成和实际提交是不同记录。

## 本机数据

默认保存在 `%LOCALAPPDATA%\ApplicationDeskV2Data`，与安装目录 `%LOCALAPPDATA%\ApplicationDeskV2` 分离。`workspaces` 中是个人、演示及独立恢复工作区；`credentials` 是 Windows 用户绑定的加密密钥，不进入备份。

工作区使用 SQLite 和托管材料副本。卸载程序不应删除工作区。更换电脑需从设置导出备份，在新电脑恢复后重新配置密钥。

旧名单导入只读取学校、项目、学位、官网、申请季及移出状态。先预览再选择，不导入旧要求、进度、材料、资格或提交记录。旧工作区保持原样。

## 官网研究

在设置中填写兼容 Chat Completions 的服务地址、模型和密钥。连接测试和研究由用户主动发起，可能产生服务商费用。研究只发送必要的公开项目资料，不自动上传个人文件或背景。

每轮最多 30 页、12 次模型请求、15 分钟；实际限制以任务记录为准。结果逐步展示，用户可采用已核实部分。停止和重启不自动继续付费调用。服务未报告 token 用量时显示未知，不当作零用量。

采用研究只建立准备依据，不保证资格、豁免、清单完整或申请材料合格。遇到来源冲突、申请季不明、登录限制或扫描 PDF，保留缺口；需要用户对照当前官网和网申确认。

## 开发

```powershell
npm ci
npm run typecheck
npm test
npm start
npm run make
```

打包后可运行 `npm run test:desktop`、`npm run test:workflow`、`npm run test:lifecycle` 和 `npm run test:ux`。四者都使用独立临时工作区；脚本中的文件选择器使用路径替身，不能替代原生对话框体验验收。实际试用步骤见 [人工验收](docs/MANUAL_ACCEPTANCE.md)。

需要 Node.js 24 与 Windows 构建环境。Electron 自带应用运行时。构建使用 Electron Forge、Webpack、React 和 TypeScript；SQLite 使用 Electron 内置 Node.js 的 `node:sqlite`。

`DESK_DATA_HOME` 可将测试数据放到独立目录，禁止自动测试使用个人工作区。`DESK_SHOW_WINDOW=0` 供自动化桌面测试隐藏窗口。

核心边界写在 [AGENTS.md](AGENTS.md)。实际检查结果及未完成项目写在 [验收记录](docs/VALIDATION.md)，开发测试不替代真实用户体验和独立环境验收。

## 首版边界

学历评估使用普通事项管理。暂不提供通知、共享评估专用办理流程、旧进度迁移、文书生成、邮箱抓取、自动网申、奖学金流程、跨设备同步或多人账户。

本地文件检查只说明可可靠提取的字数、字符数、页数以及已知长度限制，不判断内容是否符合录取要求。DOCX 不凭缓存页数作出通过结论。

代码按 MIT 许可提供。引用的学校政策与真实校徽属于相应来源；校徽副本附有 [来源说明](src/renderer/assets/schools/README.md)。虚构学校标识由代码绘制。


## 0.2.0 更新

- 年份以目标入学年份为准，支持自定义年份和可选月份；学位层次和官方学位名称分开，支持本科／硕士／博士研究。
- 学校复用、城市时区搜索、回访快捷日期；材料按名称搜索后明确选择版本。
- 会话草稿跨页面保留，正常关闭提示未保存内容；可明确放弃修改。首页行动直接进入研究、指定推荐人或提交记录。
- 旧申请季原文保留，模糊年份不猜测。升级先生成迁移备份，原要求、材料和进度保留；确认新范围后要求需要核对。
- `npm run test:ux` 检查新表单、草稿和导航行为。手工体验及真实模型结果质量见 `docs/MANUAL_ACCEPTANCE.md`，尚待验收。
