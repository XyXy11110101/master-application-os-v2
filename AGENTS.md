# Application Desk V2

This is a fresh Windows desktop application, not an extension of the old Python/NiceGUI app.
Use Electron, React, TypeScript, and SQLite. Keep user data outside the repository and installer.
Keep the old repository unchanged. Import only program identities, never old application progress.

Important boundaries:
- Evidence support, requirement necessity, personal applicability, progress, submission, and receipt are distinct.
- Research is a draft until explicitly adopted. Later drafts never silently replace adopted requirements.
- Unknown is not "not required". Incomplete details must not hide other supported facts.
- Files are copied, immutable versions are selected separately by each project.
- No personal documents or background are automatically sent to a model.
- Never invent deadlines, timezones, policy overrides, or successful checks.
- Persist before reporting success; revision conflicts must retain user input.
- Tests use isolated temporary workspaces and no paid services.

Run `npm run typecheck`, `npm test`, and `npm run make` for release validation.
Record actual UI and installer checks separately from automatic tests.
